# Rodamos

Agenda de salidas grupales en bicicleta en La Plata. Reúne fechas, horarios, puntos de encuentro, destinos, distancias y tipos de camino en un solo lugar.

**[Demo](https://marucepeda.github.io/Rodamos/)**

## Funcionalidades

- Agenda de salidas y selector de fechas.
- Filtros combinables por horario, destino, distancia y camino.
- Detalle de cada salida y enlace a su fuente.
- Formulario para proponer nuevas salidas.
- Diseño adaptable con modo claro y oscuro.

## Estado del proyecto

Prototipo funcional de MVP. Utiliza datos ficticios de demostración.

Todavía no cuenta con backend, base de datos, autenticación ni panel de administración. Las propuestas se almacenan únicamente en el navegador.

## Tecnologías
